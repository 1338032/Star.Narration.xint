星叙是纯前端工具，不提供 AI 服务。点击"生成"时，内容会发给你自己配置的第三方 AI 服务商（如 OpenAI、DeepSeek、Claude 等）。内容是否被第三方存储，取决于你所选服务商自己的隐私政策，与星叙无关。你的 API Key 只存在本地，星叙不会转发或记录。

v1.5.1 使用导览

本节说明本轮新增与调整的操作。界面中的许多功能已改为无边框图标；请结合图标位置和提示识别，不必寻找旧版的文字按钮。完整备份、资源包、作品导出是三种不同用途，不能混用。

毛玻璃效果与界面

入口：设置 → 页面美化 → 毛玻璃效果，默认开启。小说与资源卡片、设置页用户卡片使用半透明磨砂，搜索框与创作工具箱使用渐变透明；关闭后恢复普通样式（用户卡片的水波纹与边框不受开关影响）。有封面的长篇卡片只处理封面下方信息区，封面图片保持原样。设置中心搜索、收藏批量管理与折叠栏加入平滑展开和收起过渡。全屏模式开关与其他开关一样在行右侧。

第一次使用：跟着星笺起步

第一次 API 测试连接成功后，星笺会询问是否一起配置上下文提示词。点「好的」进入快速向导；点「不需要」取消后续教学。只有明确同意才进入后续流程。完成向导后进入作坊，学习长按输入框放大编辑、双击标签清空选中状态、标签最多选择六个及同类作品筛选；确认当前生效设定后再生成。第一次进入小说控制页时，星笺继续说明爱心收藏、铅笔在线编辑、快速/智能续写和定期存档备份。引导完成后可自行探索其他功能。

API：获取模型与测试连接

模型列表应以当前填写的 API 地址和密钥重新请求，不把历史拉取结果视为实时可用列表。更换接口或密钥后重新拉取，并测试实际选中的模型。拉取成功不等于模型一定可调用；权限、余额和模型下架都可能导致生成失败。拉取失败时不要把旧列表误认为本次成功结果。

人物肖像、翻转卡片与搜索

入口：设置 → 人物设定。角色卡片默认展示设定面；红色垃圾桶用于删除，旁边翻转图标切换肖像面，再点可返回。肖像面中间空白区域可上传图片，图片覆盖卡面，姓名位于右下方。翻转后卡片恢复 3:4 比例，即使之前拉长了设定输入框。性格标签默认折叠，仅显示已选标签，展开可查看全部。角色、NPC、关系三个页面顶部支持按名称、定位、关系类型或性格标签查找，清空搜索恢复列表。NPC 在编辑弹窗上传肖像，列表左图右文，不需翻转；编辑、删除为图标。

宇宙关系网：肖像模式

入口：人物设定 → 星图/宇宙关系网。重置视图与肖像模式为无边框图标。肖像模式使用人物图片替换对应天体显示，居中裁切并保持节点原形与大小；未上传图片的角色仍需保留可识别的默认显示。点天体打开人物信息卡，有肖像时顶部显示肖像，不受肖像模式开关影响。关系设置页移除外围大框，编辑与删除使用简洁图标。

世界地图：上传与进入

入口：设置 → 世界观设定 → 局部世界观下方的「世界地图」。支持 JPG、PNG、WebP，界面标注文件不超过 15MB。上传图片按 16:9 裁剪后显示。替换或清空地图前会提醒原地图数据丢失，请先确认是否需要保留。点击地图进入横向编辑视图；手机横屏呈现或方向锁定能否生效取决于使用环境，不保证所有浏览器都能锁定屏幕方向。双指缩放、拖动平移查看地图。

世界地图：分区、地点与关联线

左侧为编辑/新建工具，右侧为启用、撤回、清空、退出与保存。编辑模式默认关闭，开启后可编辑元素名称和内容。分区：依次点击地图添加顶点形成多边形，选择红橙黄绿青蓝紫之一并确认，再填写地区名称；名称显示在地区中央。编辑时点地区范围内即可操作，不必精准点击名称。地点戳：新建后出现在当前视野中心，长按移动，确认颜色、名称和内容，名称显示在图钉上方；预览时点击显示内容，过长文字以省略号展示。关联线：选两个分区或地点作为端点，设置颜色、名称与内容；名称显示在线上方，点击查看内容。编辑模式下移动地点时，关联线应随端点更新。

世界地图：启用、撤回与保存

启用地图默认关闭；开启后地图的文字设定追加至世界观提示词，不等于把地图图片直接发给 AI。撤回保留本次最多最近 30 步，退出后撤回记录重置。清空所有设置只清空分区、地点戳和关联线，不删除底图。退出不保存本次编辑，有未保存改动先确认；保存写入当前编辑并退出。地图随局部世界观及其绑定预设保存，切换项目时请确认使用的预设正确，并用完整备份保留地图数据。编辑器还提供元素列表、按名称过滤和提示词预览入口；世界观页面有带标注地图图片导出入口，其是否可见以当前地图状态为准。

完整 ZIP 备份与七天回收站

设置 → 数据管理 → 导出全部数据，生成按类别分文件的 ZIP 完整备份；导入时直接选择 ZIP，兼容旧版 JSON 备份。压缩包能正常打开且只存在部分内部文件损坏时，可继续导入其他正常文件并提示损坏数量；整个压缩包无法读取时不能承诺部分恢复。导入前先备份当前数据。旧「导出创作数据」入口已移除，作品单独导出仍与完整备份不同；资源广场资源包仍为 JSON。回收站替换原入口，全屏列表支持搜索、类别筛选、选中恢复及清空；收录创作小说、草稿、收藏长篇和短篇，仅保留七天。到期或清空后不要期待还能从回收站恢复；它不是长期备份。

伏笔追踪：从记录到回收

在阅读工具中使用伏笔追踪器，记录线索、来源章节和计划回收章节；可手动标记或用 AI 识别。查看待回收/已回收状态，结合章节或侧边栏的可用提示跟踪遗漏。需要收线时把伏笔带入续写上下文。段落跳转、回收提示词、生成后自动提取等入口仅在当前界面提供时使用：没有对应按钮或提示时，不代表已经自动完成提取或定位。AI 判断仍应由作者复核。

分卷、大纲树与章节结构

目录「新建分卷」旁的大纲树按钮与其同一行；创作页章节大纲顶部也有大纲树图标，保存改为图标。大纲树用于查看卷与章节结构，支持平移、缩放、复位及详情查看。章节排序使用目录已有拖动手柄；不要把视图平移误当成章节排序。章节目标、涉及角色、伏笔和小节层级等按当前详情表单实际提供的字段填写，不存在的字段可先写入大纲正文。

历史版本、对比与恢复

长篇章节以及 AI 短篇可通过当前界面提供的保存版本/历史版本入口保留改稿记录；重要改写前建议手动保存。历史快照预览中的「对比当前」显示与现文的差异，确认后「恢复这个版本」会替换对应内容；不采用则返回或取消。自动保存旧版的触发范围以实际改写流程为准，不能把自动保存当作每次操作的保证。历史版本不等于同一次 API 请求一定同时生成 2–3 个候选，候选数量以当前生成入口为准。

转盘、预设覆盖与快捷短语

编辑转盘 → 预设模板，关闭图标旁可保存当前转盘，保留名称与选项，转动次数默认一次。自定义预设卡片右上角提供覆盖与删除图标；覆盖将用当前转盘设置替换目标预设，执行前确认选中的名称。设置中的预设管理同样支持以当前配置覆盖已有预设或删除。编辑创作描述弹窗中的快捷短语改为限高可滚动折叠栏，不挤占上方描述框和下方操作。

入口整理与常见问题

更多功能按工具与记录、灵感与游戏、官方教程与通告等分组。收藏批量管理的取消、全选、删除、导出，以及星笺聊天清空等改为图标。磨砂开启后搜索图标消失、浏览器开关无响应、快速滑动转盘缺图、文件夹多层弹窗模糊叠加，均属于异常而非正常效果；不要通过清空创作数据处理。报告问题时记录运行方式、浏览器、复现步骤及控制台报错，先保留完整备份。

一、星叙是什么？

星叙是一款本地运行的「AI辅助创作工坊」，一个创作者为自己打造的故事宇宙工作台。比起"一键出爽文"，它更强调 你始终是作者，AI只是随叫随到的写作搭子：帮你想点子、出大纲、写段落、润色文字、管理世界观和人物设定，让长篇也能一步步写完。

所有数据都保存在你的浏览器本地（或APP内置浏览器），你可以 随时导出备份，不依赖云端账号，也不和任何平台绑定。

✦ 关于「星叙」这个名字

「星叙」的含义是：星星一样的故事，由你来叙述。谐音「心叙」，写的是故事，也是心里话。

旧称：笔记AI（biji AI）。英文名 Syn，发音 /sɪn/，取自"Narration"的核心音节，与「叙」发音高度相似；同时含"同步、共鸣"之意——与你的角色同步，与你的故事共鸣。

二、创作理念：AI是搭子，不是替身

星叙的整体设计，围绕四个原则：

  • 1）你永远是作者：AI负责“写得快”，你负责“写得对”。大纲和关键决定永远在你手里。
  • 2）设定先行：人物、世界观、规则、禁用词可以精细配置，AI续写时尽量遵守，不乱跑。
  • 3）可控而非随机：通过「上下文编辑器」「章节大纲」「情节分支器」等工具，让续写有方向，而不是抽卡。
  • 4）稳定长期使用：本地存储 + 导入导出 + 精华压缩器 + 目标统计，都是为了陪你长期写完一本书。

1）作坊：AI 写作主战场

核心区域说明：

    · 润色：不改剧情，只改文笔
    · 重写：保留剧情骨架，重新表达

    · 删除本章：慎用；章节级删除不等于整本作品进入七天回收站，操作前先保存版本或备份

  • 顶部工具：
    阅读顶部与工具面板的入口以当前界面为准，主要功能包括：
    · 🛠 工具：点击展开折叠面板，包含全部功能（沉浸阅读、语音朗读、笔记、伏笔、复制导出、AI改写等）

5）设置：所有“规则”和“设定”的大本营

API设置

  • 配置：API地址 / 密钥 / 模型 / Temperature / 最大tokens / 流式开关。
  • 反重复参数（API设置底部滑块）：频率惩罚（frequency_penalty，推荐 0.20~0.35）抑制同一词语复读；出现惩罚（presence_penalty，推荐 0.10~0.20）减少段落绕圈。默认均为 0，可点「一键应用推荐值」快速开启。两个值过高（>0.5）会让行文用词刻意，适度即可。
  • 支持保存多个 API 预设（不同平台 / 不同模型 方便切换）；预设会同时保存频率惩罚/存在惩罚两个反重复参数，切换预设时自动还原，无需手动重调。
  • 一定要用【测试连接】，确认成功后再开始写。
  • 工具API（可选）：AI评价、润色、起名等工具类功能可以使用单独的API，支持独立设置Temperature、Max Tokens和模型名。未设置则全部使用通用API。

人物设定

  • 可添加多名角色：名字、性格标签、重要度（核心/普通/参考）、详细设定。
  • 支持自定义性格标签，长按可删除（在标签管理中）。
  • 人物关系图：为人物（含NPC）添加“恋人/朋友/敌对/亲属/青梅竹马/同事”等关系，支持 AI 自动生成关系网。
  • NPC设定：单独为配角/NPC记录定位、性格、外貌、背景、出场章节。
  • 人物预设：将整套人设+关系+NPC保存为预设，便于在不同项目之间切换。

世界观设定

  • 全局世界观：所有作品通用的背景描述。
  • 局部世界观：可以和某个「人物预设」绑定，切换预设时自动切换世界观。
  • 每章最少字数：影响生成/续写时AI的目标字数（用于约束“不能写太短”）。
  • 内置模板：现代都市、古代宫廷、仙侠修真、西方奇幻、末日废土、民国乱世等，一键套用。

文风设置

  • 局部文风：可绑定角色预设，便于同一个人设用固定文风。
  • 内置模板如：轻松日常、沉郁文学、甜宠言情、悬疑紧张、古风典雅、幽默讽刺、硬核写实等。

规则设置

  • 全局规则：例如“永远1V1、不写三角恋、结局必须HE”等。
  • 局部规则：绑定人物预设，例如“这个预设下只能写古风言情”。

禁用词设置

  • 全局禁用词：常见网文通病、空洞形容、说书腔等，可一键套用模板。
  • 局部禁用词：针对特定项目或文风单独配置。
  • 建议：少而精，防止把正常词也封死。

页面美化

    · 中度：推荐，大纲式高密度
    · 重度：极简提要，适合特别长的小说
  • 支持压缩对象：
    · 人物 / 关系 / NPC
    · 世界观 / 规则 / 文风 / 禁用词
    · 额外设定（上下文、伏笔清单、大纲等手动粘贴）
  • 压缩结果不会直接覆盖原设定，而是：
    · 保存为预设（世界观/规则/文风/禁用词）
    · 或变成文本，供你手动粘贴到需要的地方

数据管理 & 安全

  • 导出全部数据：建议定期导出为 ZIP 压缩包备份（内含按类别分好的多个文件；导入时某个文件损坏不影响其他文件，并会提示损坏的文件个数；旧版 JSON 备份仍可导入）。

  • 清空作坊 / 清理旧数据：删除一段时间前未收藏的作品，释放空间；清理时同步删除关联笔记和上下文，不留孤儿数据。

  • 生成日志：记录每次生成/续写用到的 system + user 提示，方便排查“为什么写偏了”。
  • 清理旧日志：防止日志体积过大。
  • 回收站：删除的小说、草稿（含收藏页的长篇、短篇）会先放进回收站，保留 7 天，到期自动清除；可在数据管理里搜索、按类别筛选、恢复选中内容或清空回收站。

8）继写番外篇：给故事一个温柔的附录

在阅读页的工具栏中，你可以找到「 继写番外篇」功能。

这是什么？

番外篇是一种独立于正文之外的小故事。它可以是主角婚后的日常、配角的视角、"如果当初..."的平行线，或者发生在很久以后的一次重逢。番外不需要推进主线剧情，更注重情感和细节。

核心功能：

  • 长篇短篇通吃：无论是长篇连载还是短篇一发，都可以续写番外
  • 篇数可选：1-3篇，每生成完一篇自动暂停，你确认满意后再生成下一篇
  • 原作摘要：
    · 短篇：自动填充原文全文，AI完整记住你的故事
    · 长篇：点击「🤖 AI总结」自动提炼核心剧情，也可以手动补充
  • 每篇独立大纲：可以为每篇番外单独设置剧情方向（也可以留空让AI自由发挥）
  • 防重复机制：后续番外会参考前面已写的番外摘要，不会写出雷同的内容
  • 生成后操作：阅读全文、复制、保存为草稿、收藏为短篇、删除

使用建议：

  • 番外的核心是"情感补充"，不需要宏大的情节，一个小细节就能打动人
  • 在大纲里写清楚你想看什么——"婚后日常""从某某视角看""五年后的某天"——AI会更听话
  • 如果原作是虐文，番外可以写甜的，反过来也行，番外就是用来弥补遗憾的
  • 长篇作品建议先用AI总结再生成番外，总结越精准番外越不跑偏

这是什么？

角色模拟是一个独立的「纯对话」模式——你创建一个角色（填写人设、性格、说话方式），然后像在聊天软件里一样和他/她对话。角色只说"话"，不写动作描写、心理旁白，最大程度还原真实聊天感。

底部导航：通讯录 / 添加角色 / 设置。设置页内含「API设置」「页面设置」「数据管理」「其他设置」四个分组：
· API设置：可单独覆盖角色模拟使用的接口（留空则跟随星叙当前API）
· 页面设置：背景图、气泡颜色、全屏模式（隐藏浏览器顶部栏和工具栏，按屏幕大小自动铺满，视觉上更像一个独立APP）、全局字体（可填自定义字体链接，也可用内置字体）；原「其他设置」里的角色流式输出、消息分段、时间感知开关已迁移到这里统一管理
· 数据管理：点击进入全屏弹窗，内含存储概览面板、清理与压缩（清理缓存/垃圾数据，压缩现有数据不影响使用，图片缓存也会一并清理）、清空所有数据（仅清空角色模拟数据，星叙数据库不受影响），以及导入/导出（仅角色模拟数据）
· 设置页最下方有一行小字标注当前版本「角色模拟 v1.1.1 星叙配套」

  • 日记：查看/生成角色日记，支持手动和自动定时生成

八、常见问题（FAQ）

Q1：API老是报错 / 生成失败怎么办？

  • 检查 API 地址是否写成了完整形式（含 https://）。
  • 检查路径是否多写了一层 /v1（有的接口已经自带）。
  • 确认密钥有效、账号有余额。
  • 尝试换一个模型名称；不同平台模型名不一样。
  • 如果开了“流式输出”却报错，可以先关闭再试。

Q2：续写为什么总是跑偏 / OOC？

  • 降低创意度（0.6-0.7）。
  • 试试「🧠 智能续写」（绿色按钮），自动分析前情+角色状态+伏笔后再续写，比快速续写更稳定；关键章节可用「💎 精品续写」，AI 会先给你看本章规划，确认后再正式创作。
  • 在「上下文设置」（全屏弹窗）里写：
    · 章节大纲：一章一格，AI严格按大纲续写；多章连写时会注入全部/当前章大纲
    · 故事梗概 & 核心理念/主题：整本书的设定，AI每次续写都会参考
    · 写作方向设置：告诉AI这次具体要写什么，多章续写时务必填写
    · 已确立事实：锁定不可逆的剧情节点（如"某物已被摧毁"），AI 绝对不会违反
    · 前情提要（可用AI生成后自己修）
    · 人物当前状态 & 重要伏笔（伏笔追踪器里的内容会自动注入，无需手动复制）
    · 特殊要求
  • 开启「生成后一致性检测」（设置→其他设置→续写质量反馈），续写完成后 AI 自动检查内容是否与设定冲突，发现问题可一键重写。
  • 利用"章节大纲"和"伏笔追踪器"把关键线索写清楚。
  • 设定写太多太散时，用精华压缩器做一个"浓缩版"人设 / 世界观。
  • 善用「章节版本管理」：不满意时保存当前版本，然后大胆重写对比。

Q3：生成的文字感觉很流水账怎么办？

  • 输入时多强调“冲突”和“转折”，例如：
    · “开局是一次失败的告白”
    · “中间一定要有一次误会”
    · “结尾留一个悬念：其实信不是他寄的”
  • 完善人物设定：性格矛盾、欲望和恐惧。
  • 使用禁用词减少“空洞描述”和“万能副词”。
  • 生成后用「AI评价」查看弱点，然后针对性地用「重写/扩写/润色」优化。

Q3-5：生成内容出现段落重复 / 同一句式写了好几遍怎么办？

  • 在「API设置」底部找到「反重复参数」区域，开启 频率惩罚（推荐 0.25）和 出现惩罚（推荐 0.15），或直接点「一键应用推荐值」——这是从模型层面解决问题，效果最直接。
  • 降低每章字数目标（建议 1200~2000字），字数设置越高 AI 越容易水字数。
  • 智能续写 / 精品续写内置了「反重复铁律」提示词，比快速续写更稳；如果仍然重复，可以用「精品续写」，第一步的章节规划会约束每段必须写什么。
  • 还是重复的话，续写后用「AI重写」针对有问题的段落重新生成。

Q4：数据会不会丢？

  • 数据保存在浏览器本地（或APP内置浏览器），清理浏览器数据可能导致丢失。
  • 建议：
    · 初次配置好 / 写出第一篇满意作品后 → 导出一次数据备份
    · 每周或每月定期导出备份
    · 换设备前先导出，在新设备导入

Q5：锁屏忘记密码怎么办？

  • 如果设置了备用问题，可以在锁屏界面选择“忘记密码”，回答正确后重设密码。
  • 如果没设置备用问题，则无法直接找回，只能导出数据或联系作者寻求建议（但作者也无法直接解锁你的浏览器存储）。

每日灵感打卡

  • 每天自动刷新一条创作主题（如「一个被所有人遗忘的名字」），同一天主题固定不变；若想换一条，直接点击主题文字即可随机切换，每次不重复当前主题

素材库管理

  • 搜索与筛选：顶部搜索框全文搜索（标题/内容/标签），关键词高亮显示；标签胶囊单击筛选，横向滚动；排序方式点胶囊选择（最新/最旧/收藏优先）

  • 批量操作：点右上角「选择」进入批量模式，可批量打标签/AI标签/删除
  • 点击卡片直接进入编辑；长按卡片弹出右键菜单（收藏置顶/AI润色/删除）

素材 AI 功能

  • AI 标签推荐：编辑素材时，标签区点「AI推荐」，自动分析内容生成4-6个分类标签，点击即可采纳
  • 精简扩写 / 深度丰富：编辑器中，对文本内容或图片描述点对应按钮，AI 润色后进入对比模式（原文 vs AI结果），可选「采用」或「放弃」
  • AI 识图描述（图片模式）：上传图片后点「识图描述」，AI 自动生成图片描述文字和分类标签（需模型支持视觉理解）
  • 批量 AI 标签：批量模式下选中多条文本素材，点 AI 图标，逐条自动生成标签（间隔0.8秒防限流）

素材用于创作（最核心的功能）

    ·「注入写作方向，续写当前书目」：素材以「【素材参考】」追加到续写上下文的写作方向中，下次续写时 AI 会参考
  • B. 在创作流程中引用素材（在已打开的创作弹窗内）：
    ·「编辑创作描述」弹窗右上角图标 → 选择素材 → 插入描述框

    ·「AI 改写」弹窗「从素材库引用创作素材」→ 追加到重写需求
    ·「番外篇」原作摘要区「引用素材」→ 追加到原作摘要
  • 素材选择器支持实时搜索，按最近更新排序，最多显示60条

  • 记忆管理（顶部大脑图标）：故事摘要（AI自动总结或手动编辑）、自动后台总结、关键事实锁定、全书梗概生成（替代原文节省Token）
  • 世界状态面板（顶部地球🌐图标）：AI每次回复后自动提取并追踪故事当前的时间、正在发生的事件、人物所在位置与关系状态、关键物品持有者，随剧情实时更新，点击地球图标即可查看当前世界快照
  • 快捷操作栏（对话框上方胶囊）：黄色=插入场景分隔线；紫色=自定义快捷键（支持光标位标记和拖动排序）；绿色=快捷短语（一键发送预设指令）；快捷键和快捷短语的排序调整逻辑现已和星叙保持一致，操作更顺手

  • 系列关联：多部续集可关联成系列，共享绑定设定，前作总结自动传递给续作
  • 阅读与导出（旅途选项内）：小说阅读模式（全屏沉浸，支持竖排）、导出排版HTML/Markdown、导出TXT、搜索对话内容

星叙的创作立场声明

星叙从诞生之初，就明确反对用 AI 批量生成低质内容、刷平台、代笔代写等行为。

我开发这个工具的初心，不是为了让 AI 代替人类写作，而是希望给真正热爱创作的人，提供一个强大、私密、好用的辅助创作工作室。

我坚信：好的故事永远来自作者的真情实感、人生经历和独特思考，AI 无法取代。AI 应该是创作者的"灵感伙伴"和"高效助手"，而不是写作的主体。

最终呈现在读者面前的每一部作品，都应该由作者本人主导把控、修改打磨，并对内容负责。

如果您也认同"人类创作 + AI 辅助"的理念，欢迎使用星叙。如果您期待的是完全由 AI 自动生成小说然后直接发布的工具，那么星叙并不适合您。

我会继续把星叙做成一个尊重创作者、尊重原创的工具，也欢迎大家在合理使用的前提下，一起维护健康、良性的创作生态。

—— 心田（星叙作者）

星叙是什么

星叙是一个 AI 辅助的同人 / 网文创作工坊：一句话描述就能生成长篇第一章或完整短篇，还配有人物、世界观、文风、规则等精细设定，伏笔追踪、时间线、版本快照、素材库等工具帮你把一个想法慢慢养成一整本书。数据全部存在本地，随时导出备份，不强制联网、不强制登录。

创作理念

星叙的整体设计，围绕四个原则：

  • 你永远是作者：AI负责"写得快"，你负责"写得对"，大纲和关键决定永远在你手里。
  • 设定先行：人物、世界观、规则、禁用词可以精细配置，AI续写时尽量遵守，不乱跑。
  • 可控而非随机：上下文编辑器、章节大纲等工具让续写有方向，而不是抽卡。
  • 稳定长期使用：本地存储 + 导入导出 + 精华压缩器 + 目标统计，陪你长期写完一本书。
为什么创造星叙 · 开发者的话

开发者心田是个喜欢写小说的学生党，最初只是想给自己做一个够用的辅助创作工具，没想到在用户的支持下，慢慢做成了现在的样子。星叙不收费，也不打算收费，所有功能免费开放。
